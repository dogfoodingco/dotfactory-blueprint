# Planning and Verifying reuse the project's feature map

- `verified-plan.md`, `verified-verify.md` and `work.md` read a project's existing verification guide and feature map in place, if present. Planning records selected cases, durable effects, prerequisites, non-claims and uncovered paths; Verifying runs affected cases and carries gaps into `.factory/delivery.json` limitations. `factory/WORKFLOW.md` re-rendered.
- Map prose is reference material: it never registers a method, grants execution authority or replaces the host receipt. No new state or host check. [ADR-0051](../decisions/0051-reuse-project-verification-maps.md).
